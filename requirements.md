# Requirements for university course planner python application.

## Overview, this python application is meant to be used by an academic advisor, or someone who is responsible for ensuring students are assignd correct module. Future aspect of the application can include the student view.

## The Functional Requirement
1. Academic advisor(add a module).
2. Prerequisite relationship can be added
3. Academic advisor can register a student and record completed modules
4. Generating study plan
5. Detecting and reporting unrealistic study plans
6. JSON file (saving and loading data)
7. ensure there a core functionality
8. GUI using Tkinter

Above is the major fuctional requirment is application will cover, they are also on GITHub issues and i will be closed when there is a valid commit that implemets the requirement.

## Out of Scope
- Student view
- lecturer view, teaching assignment, grading
- use of real university data, external APIs
- GPA
- Web or mobile frontend
